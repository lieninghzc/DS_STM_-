# MaixCAM ↔ MCU UART 通信协议

## 硬件连接

```
MaixCAM (UART1)          MCU (MSPM0G3507)
    TX  ──────────────→  RX
    RX  ──────────────→  TX
    GND ──────────────→  GND
```

## 串口参数

| 参数 | 值 |
|---|---|
| 端口 (MaixCAM) | `/dev/ttyS1` |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |

## 数据格式

**ASCII 文本，每帧一行，换行符 `\n` 结尾。**

```
{lr},{dist}\n
```

| 字段 | 含义 | 值 |
|---|---|---|
| `lr` | 钢球相对于原点的方向 | `1` = 右侧, `0` = 左侧 |
| `dist` | 钢球中心到原点的欧氏距离 | 整数, 单位 px |

## 示例

```
1,15\n    → 原点右侧, 距离 15px
0,8\n     → 原点左侧, 距离 8px
1,0\n     → 原点右侧, 距离 0px (球在原点)
0,42\n    → 原点左侧, 距离 42px
```

## 原点标定

- 首次检测到钢球后，取 **4 帧坐标平均值** 作为原点
- 标定过程中 MaixCAM 打印 `calibrate N/4`
- 标定完成后打印 `origin set: (x, y)`
- 原点建立后开始向 MCU 发送数据

## 数据频率

- 每帧发送一次（约 30 FPS）
- 未检测到钢球时 **不发送** 数据

## MCU 解析示例 (C)

```c
char buf[32];
int lr, dist;

// 读取一行
uart_gets(buf, sizeof(buf));

// 解析 "lr,dist"
if (sscanf(buf, "%d,%d", &lr, &dist) == 2) {
    if (lr == 1) {
        // 球在原点右侧, 距离 dist px
    } else {
        // 球在原点左侧, 距离 dist px
    }
}
```
